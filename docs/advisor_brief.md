# Advisor Brief

## Research Direction

Trustworthy AI systems for enterprise document intelligence.

## Project Summary

PDF Manager is a document intelligence toolkit for OCR, layout preservation, structured extraction, and PDF operations. The research layer evaluates how layout-aware extraction supports downstream retrieval and citation-grounded QA.

## Why This Matters

Enterprise and financial AI systems often begin with messy PDFs. If extraction loses sections, tables, or page references, downstream RAG systems become less trustworthy.

## What I Built

- PDF processing toolkit.
- Structured extraction schema.
- OCR and chunking evaluation plan.
- Sample extraction result and proof-layer comparison table.

## What I Evaluated

The proof layer compares raw extraction, OCR-only extraction, fixed chunking, and layout-aware extraction on sample section accuracy, retrieval recall, citation accuracy, and failure count.

## What I Can Contribute To A Lab

I can help with document processing, OCR evaluation, layout normalization, RAG data preparation, error analysis, and reproducibility documentation.

## Possible MSc/RA Extension

This project could become a capstone on layout-aware document retrieval for financial or enterprise PDFs.
